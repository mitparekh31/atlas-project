# project Atlas
Project Atlas is production ready cloud native platform built to simulate real-world enterprise applications. This Project is designed to demonstrate practices in Docker, kubernets, jenkins, GitHub actions, ArgoCD, Grafana, Helm, AWS, Teraform, AWS and other cloud native technologies. 

# project overview

Project Atlas is a production-ready cloud-native platform designed to simulate a real-world enterprise application.

# Objectives

An objective of project atlas is to make good hands-on experience of all cloud native technologies
